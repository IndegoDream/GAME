# scripts/

- `core/` -- the game itself: state, saves, store, voice, audio, art, platform bridges
- `world/` -- places and how they are built and dressed
- `actors/` -- the player and everyone who moves
- `objects/` -- things that stand in a level and can be used
- `fx/` -- effects
- `ui/` -- screens and HUD
- `systems/` -- the modular systems (GameSystem.gd children)
